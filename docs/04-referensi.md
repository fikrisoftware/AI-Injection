# Referensi dan Bacaan Lanjutan

Kumpulan rujukan untuk memperdalam materi. Sumber-sumber ini berorientasi
edukasi dan pertahanan.

## Kerangka Kerja dan Standar

- **OWASP Top 10 for LLM Applications** - kategori **LLM01: Prompt Injection**
  dan kategori terkait (mis. Insecure Output Handling, Excessive Agency).
  Rujukan utama untuk klasifikasi risiko aplikasi LLM.
  [https://owasp.org/www-project-top-10-for-large-language-model-applications/](https://owasp.org/www-project-top-10-for-large-language-model-applications/)
- **OWASP GenAI Security Project** - panduan dan materi keamanan AI generatif.
  [https://genai.owasp.org/](https://genai.owasp.org/)
- **NIST AI Risk Management Framework (AI RMF)** - kerangka manajemen risiko
  untuk sistem AI.
  [https://www.nist.gov/itl/ai-risk-management-framework](https://www.nist.gov/itl/ai-risk-management-framework)
- **MITRE ATLAS** - basis pengetahuan taktik dan teknik serangan terhadap
  sistem machine learning.
  [https://atlas.mitre.org/](https://atlas.mitre.org/)

## Prompt Injection (Direct dan Indirect)

- Simon Willison - seri tulisan tentang prompt injection, termasuk pola
  exfiltrasi dan konsep **dual-LLM pattern** untuk pemisahan hak istimewa.
  [https://simonwillison.net/tags/prompt-injection/](https://simonwillison.net/tags/prompt-injection/)
- Greshake dkk. - *"Not what you've signed up for: Compromising Real-World
  LLM-Integrated Applications with Indirect Prompt Injection"* (makalah yang
  mempopulerkan istilah indirect prompt injection).
  [https://arxiv.org/abs/2302.12173](https://arxiv.org/abs/2302.12173)
- **Gandalf** (Lakera) - permainan edukatif untuk memahami ekstraksi rahasia
  melalui prompt.
  [https://gandalf.lakera.ai/](https://gandalf.lakera.ai/)

## Tool Poisoning dan Keamanan MCP

- **Model Context Protocol (MCP)** - spesifikasi dan dokumentasi resmi,
  termasuk pertimbangan keamanan.
  [https://modelcontextprotocol.io/](https://modelcontextprotocol.io/)
- Materi komunitas mengenai **tool poisoning**, **rug pull**, dan **tool
  shadowing** pada ekosistem MCP (mis. publikasi Invariant Labs dan riset
  keamanan terkait). Cari istilah "MCP tool poisoning attack".

## Panduan Vendor

- **OpenAI** - dokumentasi keamanan dan best practices function calling.
  [https://platform.openai.com/docs/guides/function-calling](https://platform.openai.com/docs/guides/function-calling)
- **Anthropic** - panduan keamanan penggunaan tools/Claude dan MCP.
  [https://docs.anthropic.com/](https://docs.anthropic.com/)
- **Google** - Secure AI Framework (SAIF).
  [https://saif.google/](https://saif.google/)

## Catatan Penggunaan

- Tautan eksternal dapat berubah seiring waktu; verifikasi kesegaran sumber
  saat mengembangkan konten website.
- Prioritaskan sumber primer (spesifikasi, makalah, dokumentasi vendor) untuk
  akurasi teknis.
